# 充电会话离线清分服务（含计量固件灰度结算护栏）

用于拼接站点离线补传的充电计量片段，并在新计量固件进入日结链路前，用**同一批会话、两套冻结规则**并行试算，
明确回答：哪些设备可晋级、哪些必须隔离、金额差异来自哪里。项目采用 Koa 与 TypeScript + SQLite，
保留独立迁移进程和可注入的应用构造函数。

## 本地约定

- 数据库默认写入 `data/charging.sqlite3`，可通过 `APP_DB_PATH` 改为其他文件。
- 金额一律以**分（整数）**存储；时间一律 ISO8601；站点本地时区用 `APP_LOCAL_UTC_OFFSET_MINUTES`（默认 +08:00）。
- 服务不需要远程数据库或缓存。

## 常用命令

```bash
npm install
npm run db:upgrade
npm test
npm run demo      # 生成 reports/canary-report.md 与 reports/trace-example.json
npm start
```

Docker 镜像在构建阶段执行自动化测试，运行时监听 `PORT` 指定的端口，未设置时使用 8080。

## 灰度护栏如何工作

1. **发布波次限定范围**：每波绑定站点、设备型号、校准批次，以及冻结的现行规则（`metering-v1`：
   平价、整片归会话起始日、读数回退整片丢弃）与候选规则（`metering-v2`：跨零点切段、
   凭固件声明保留复位后能量、峰平谷 TOU）。范围外设备无法被认领。
2. **唯一认领**：同一时刻一台设备只有一个 `active/promoted` 波次认领（部分唯一索引兜底），
   两个波次同时认领被拒绝。
3. **签到**携带固件摘要、安装时刻、回滚缘由；同一（设备，摘要，安装时刻）重复回报不新建记录。
4. **跨固件版本会话**：累计表读数原样保留，每个片段关联其发生时的固件。
5. **双规则试算与归因**：每个完整会话同时按两规出账，差异严格分解为
   `跨零点迁移 + 异常复位找回 + 峰谷价差`，三项之和恒等于总差异；跨零点迁移只在相邻账期间搬运，
   波次净额为零（仅整数分四舍五入残差）。
6. **门槛裁决**：负增量会话占比、缺片率、最少样本量、金额差异率与绝对金额差共同决定
   `promote / quarantine / blocked`；超限设备认领置 `isolated`，禁止新会话。
7. **双签放行**：计量负责人与清算负责人分别 approved 后才允许晋级；晋级后新会话按候选规则出账。
8. **封账不变性**：账期封账后离线补传可以迟到，但不改账，只生成调整建议（`adjustment_advices`）。
9. **回滚保留**：回滚释放认领、后续会话回落现行规则；已按候选规则入账的结算行与采用过的规则版本原样保留。
10. **可续算 + 可反查 + 守恒**：比较作业以会话为最小事务单元，中断后从已完成会话续算；
    日结人员可由一笔差异反查固件、冻结规则、读数区间、作业 `input_hash/run_id` 与双签审批版本；
    波次汇总通过分量恒等、跨零点净额、设备=会话两级合计等守恒校验。

## HTTP 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查 |
| GET | `/waves/:waveId/report` | 灰度报告 JSON |
| GET | `/waves/:waveId/report.md` | 灰度报告 Markdown |
| GET | `/waves/:waveId/trace/:sessionId` | 一笔差异的完整证据链 |
| POST | `/waves/:waveId/compare` | 触发/续算比较作业（幂等） |
| POST | `/waves/:waveId/approvals` | 计量/清算负责人双签 |

## 模块布局

- `src/rules.ts`：冻结规则定义（只追加、不就地修改）。
- `src/engine.ts`：双规则计量引擎、切段/复位/TOU、金额三分量与 `input_hash`。
- `src/service.ts`：设备/波次/认领/签到/会话片段/封账/审批/晋级/回滚工作流。
- `src/jobs.ts`：可续算比较作业、门槛裁决与封账后调整建议。
- `src/reporting.ts` / `src/report-markdown.ts`：报告聚合、守恒校验、差异反查与报告渲染。
- `scripts/demo.ts`：确定性演示数据与灰度报告生成。
- `test/`：引擎、工作流、端到端生命周期、HTTP 共 29 个用例。
